Praktik PC BIOS

Disassembly of every available BIOS version of the Soviet IBM-compatible Praktik computer, with a comment on every line and a version history.

Important. The Praktik motherboard power connector looks like the standard IBM PC 5.25-inch floppy drive power connector, BUT(!) its pinout does not match the standard one. Connecting a standard IBM PC power supply burns out the chips on the motherboard. Check the pinout before applying power.

Listing

Each version also has a plain-text .asm listing with the same comments. The version order is confirmed by code similarity: dk and 2.16-17 match by 87%, 2.16-17 and new by 84%, dk and new by only 71%.

How the machine works

All versions share one principle. The Praktik has no 8259 interrupt controller and no 8237 DMA controller. The other chips (8255, 8253, 6845, 765, 8250) are not on the standard IBM PC I/O ports but in a memory window at F000:0000–0FFF. A program's access to a standard port raises an NMI, and the handler in ROM carries it out in software. That is how ordinary IBM PC software runs on different hardware.

The 16 KB ROM image is visible at FC000–FFFFF and in a mirror at F4000–F7FFF. The first 8 KB run as segment F400: the peripheral emulator, the common interrupt handler INT 0Fh and the upper half of the font. The second 8 KB are an ordinary BIOS with IBM PC/XT entry points. The full register and port map is on the 2.16-17 page.

What changed between versions

2.14-15_dk → 2.16-17

  • Port lookup in the NMI handler: dk scans a list of 25 ports with repne scasw; 2.16-17 uses a 1024-entry table and dispatches in one step.
  • Emulation of two 8250 serial ports (2F8–2FF, 3F8–3FF) and COM1/COM2 detection at boot were added. In dk the COM ports are never found and INT 14h returns immediately.
  • INT 10h AH=0 writes the 6845 registers directly to F000:0000/0002 instead of going through the emulated ports.
  • Joystick: hardware one-shots replaced by software axis simulation.
  • The beep and COM port detection moved to segment F400 and are called through the ROM mirror. Word-sized register writes in POST were fixed.

2.16-17 → 2.18-19_new

  • INT 18h runs the LANcom 1.2 network loader (F400:0C4F) instead of the tape loader. The network runs over the second 8250 (COM2) on a shared line. The file \\SERVER\RLOAD\NETBOOT.@@@ is downloaded over SMB and mounted as RAM disk A:.
  • Pressing Del during the memory test starts network boot right away, bypassing the floppy drives.
  • The tape loader is still in ROM but unused. The model byte is changed to FDh.
